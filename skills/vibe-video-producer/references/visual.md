# 视频风格

## 世界观卡（一页，先于分镜）

```
贯穿物：            它怎么变形：
主角：              （默认无脸，靠姿势和位置说话）
概念质地 → 画风：
底色：      角色色 A（代表谁）：      角色色 B（代表谁）：
亮度曲线：几秒暗、几秒亮，哪一刻想通
开头画面 = 结尾画面：意义怎么变了
仪表：角落持续变化的数字是什么
转场：前后两幕在空间或因果上怎么连（推进一张纸、缩进地图上的一个点、越过一面墙）
禁止：
```

## 规律（拉片）

1. **一片一物**：比喻从头走到尾，约 20 条结尾回到第一个画面。
2. **长片几乎不切**：91–170 秒的片子每分钟硬切中位约 1.6 次，靠同一个世界持续变形。
3. **暗场是常态，但不是必要条件**：约 40 条深色底，一屏只有一个亮点；也有红底黄花这样的亮色爆款。
4. **亮度是情节**：暗到亮 = 想通了。
5. **颜色分角色**：两种颜色代表两个人，或代表“活着”和“变凉”。
6. **人物无脸**：观众才能代入，也省动画。
7. **三层文字**：大字概念、字幕、角标（章节、来源）。
8. **数据就是画面**：一个点代表一个人，用数量本身吓人。
9. **反差**：前半段极简线条，点题瞬间切金光大图。
10. **角落仪表**：年龄、年份、计数持续变化，代替转场提示。
11. **一个视角讲完**：只用俯视一个教室，或把聊天画成打乒乓。比喻由内容包给出，制作负责让它成立。
12. **转场要有因果**：前后两幕在空间或因果上连起来，元素像属于同一张画；硬切和各演各的最容易被说“割裂”。

## 两种创作方式

两条路都收束到 `treatment.md`，下游流程一样。

**原创**：从题的质地出发，先定一个世界：这里的物理规则是什么，贯穿物在这里怎么动。然后从 `libraries/styles/` 选最近的画风改，没有就新建一个文件。给 2 个方向时说清每个方向的世界观，不要只说好看。

**参考**：用户给了案例，先跑 `npm run reference -- <案例.mp4> --id <id>`，看联系表和测量数字，写清学的是哪几处手法（节奏、转场、动效和音效的场合）。颜色和字体不学，除非用户点名照参考片。原句、画面设计和原片素材不搬。

想积累自己的画风参考库，放在 `references/private/style-library/`（不进 git），每条留原片和联系表，按画风分类。

不要把样本的做法说成必须。贴拍和剪辑参数拉不开差距（**数据**），世界观是否原创对数据的影响也没有证据（**假设**）。

## 选画风

现有画风在 `libraries/styles/`（`npm run studio` 里有预览）：天鹅绒舞台、水墨、陶罐红绘、蓝图线稿、皮影、静夜、纸拼贴、朱砂线描、宋纸海岸、宋代长卷、皮影剧场、汉风扁平信息图（han-flat）、彩色几何平涂图解叙事（geo-flat）。预览只是配色和质感卡，不代表成片效果。

问“这个概念的质地是什么”：

| 题 | 画风 | 为什么 |
|---|---|---|
| 柏拉图 | 古希腊陶罐红绘 | 风格就是时代 |
| 宿命 | 建筑蓝图线稿 | “写好的剧本” = 设计图 |
| 秦始皇 | 朱砂线描 | 帝王、血、火 |
| 虚无 | 星点连线 | 什么都没有，只有几个点 |
| 城市路网 | 夜景车流光带 | 拥堵一眼看见 |
| 埃及神话 | 古埃及壁画 | 文化本身的画法 |
| 山海经 | 黑白皮影 | 古意 |
| 三国故事 | 汉风扁平 / 几何平涂图解 | 人物、地图、数字一起讲清楚 |

不要默认黑底金字：样本里已经很多，撞款风险高。字体和配色用自己的，定在画风文件里。

## 密度

长片约每 10 秒一个明显画面事件（5.8 个/分），≤31 秒的片子约每 2 秒一个（27.7 个/分）。

## 角色表演和音乐落点

有角色时先定这一拍要观众看哪一件事，再安排起步、走动/跳跃、停步、指引与退场；准备、完成、恢复各有任务。姿势不是把整体来回平移或所有关节一起摆，读字时可停。

换角度后核实际手端轨迹和支撑脚的世界坐标，手与物的接点必须成立；指引就留净空，不能看着像托着拿着。尾带、胡子、袖口这些跟随部件，用同一个“动作往前、垂饰往后甩”的方向约定，不要各甩各的。先后关系、最近音乐帧与 0.2 秒连续查帧方法见 `references/beat-sync.md`。
