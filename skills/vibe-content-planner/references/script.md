# 字幕稿与口播稿

约九成样本没有人声（**拉片**，两批 74/82），字幕就是脚本。观众在用自己脑子里的声音读。

历史、讲书、人物故事先按 `references/story-hooks.md` 设计知识切入，示例见 `references/story-examples.md`。以下屏数、行长和首屏速度只用于纯字幕片；口播保留自然语序与完整意思，不因字幕阈值切碎句子。口播体检用 `scripts/check_script.mjs` 的 `--voiceover` 模式，估时只是参考，实际时长以试读或最终人声为准。

## 长度

- 总字数 ÷ 4.5 ≈ 秒数。长片样本中位约 5 字/秒（含图内标签）。
- 一屏 1–3 行，一行约 16 字以内，关键句单独成行。
- 每句最多一个词上色，颜色有固定含义。

## 第一句

纯字幕首屏争取尽快读完，字与当下讲的事情一致；2 秒是制作参考，不是所有口播第一句的硬限制。下面的例句是为说明类型写的，不是样本原句。

| 类型 | 点赞中位（数据，样本小） | 例 |
|---|---|---|
| 反常事实 | 24.6 万（27 条） | 越是摔得高的猫，越容易活下来。 |
| 点名处境 | 29.2 万（20 条） | 聚会散了，你一个人坐在回家的车上。 |
| 事件判决 | 18.1 万（12 条） | 他修了长城。他统一了文字。他被骂了两千年。 |
| 提问猜谜 | 18.3 万（14 条） | 这段旋律你一定听过，它一共用了几个音？ |

概念字幕可参考前两种；故事类按材料选择问题、动作、对白、具体处境或直接判断，不把样本中位数当因果证据，也不规定每篇反常或反问。

故事开头先判断普通观众为什么愿意听；可先提出话题，再进入具体事件。陌生名字可后揭；正文的转折和结果要回答开头，不能标题问一件事、正文只讲另一件事。

## 四种结构

**哲学一喻（90–170 秒）**：处境 → 接住 → 命名 → 生活例子 → 破常识 → 比喻升级 → 翻转 → 回到开头。比如从“跑到第二圈想停下”开始，几秒后点出哲学家的名字和概念，再用背单词这类日常例子落地，中段把常识翻过来，结尾回到跑道，意思已经变了。

**证据链（85–160 秒）**：反常事实 → 给个错误解释 → 换领域再举例 → 回来揭真相 → 再跳一次 → 生活三连 → 一个人的命运 → 留问。中段换领域防止疲劳，结尾的人物命运把知识变成故事，这两步最值得学。

**短片压缩（13–45 秒）**：三连处境 → 命名 → 一句反转。翻转可以做两次，比如把一句名言划掉，改写成反过来的意思。

**假如你是（100–190 秒）**：一句绝境 → 片名 → 按时间线走一生 → 回到开头那一刻 → 结局 → “如果是你”。全程用“你”，每段写年龄或年份，交给制作做成角落计数。

讲神话也可以用证据片或故事走法，开头按事实选择值得追问的入口，不强制反常句。

## 点题时机

- **前置**（≤10 秒）：名字或话题本身已提供观看理由时可前置。短片和哲学片常用。
- **后置**：先讲故事，名字是奖励。证据片常用。

点题早晚的点赞差别不大（23.5 万 vs 27.4 万），按结构选。

## 句法

### 去掉 AI 口吻

- 用当面讲故事的自然语序，把谁做了什么、遭遇了什么说清楚。
- 用具体事件承接情绪。“他还得再走一遍”没说清挫折，就按史料写出再次被贬、失去亲人等实际遭遇。
- 少用刻意抒情的倒装、抽象概括或隐喻代替动作。说有人帮助，就直接讲帮助。
- 转场根据事件的变化来写，避免连续机械使用“后来”。
- 用户给出的替换句原样采用；只改指定位置及必要衔接。交稿前通读，检查“当面讲这个故事，会这么说吗”。

以下句法手法按内容需要使用，不为套结构硬加悬念、反转、抒情或总结。

| 手法 | 例 | 作用 |
|---|---|---|
| 破折号悬停 | 而真正出问题的那一块—— | 字停着，让下一个画面回答 |
| 回收句 | 现在，回到开头那只猫。 | 提醒没跑题 |
| 否定再定义 | 他不是在欢呼，是在报丧。 | 替换观众原来的理解 |
| 让读者先答 | 如果是你，会选哪一个？先想 3 秒 | 制造参与，配静止画面 |
| 替观众反驳 | 你可能会说：小孩子嘛，三分钟热度。 | 先堵住质疑 |
| 具体数字 | 3652 天、0.3 秒 | 用数字代替情绪词 |
| 生活三连 | 三句大家都听过的话 | 把理论落到生活 |
| 留余地 | 也许、论文推测、这是相关，不是因果 | 诚实，也更安全 |

## 结尾

- **断言**：落在一句可以被截图的话上。
- **问句**：丢回观众自己。
- **评论任务**：让人能动手，比如“用这五个音写一段旋律”。比“点赞关注”自然。

断言和问句的点赞接近（24.6 万 vs 26.7 万）。最后一屏放片名、一句话和来源，字慢慢淡掉。

## 自检

- 删掉所有形容词，还站得住吗？
- 对外话题、主事件和开头是否对应，正文讲完是否回答观众最初的问题？
- 讲述是否持续有信息、人物行动或事情变化？不按固定秒数硬塞转折。
- 有没有哪句只是在解释上一句？
- 事实表每条都有来源吗？
