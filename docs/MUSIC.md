# 音乐怎么决定画面

写谱之前先回答：这部片里，观众的情绪应该在哪一秒转弯？

## 从内容到谱子

| 内容里的东西 | 音乐里对应 |
|---|---|
| 贯穿物 | **动机**：三五个音，只属于它。物出现，动机出现 |
| 角色或立场 | 音色和音区。两个人用两种音色 |
| 处境 | 引子：单件乐器，主和弦，留白多 |
| 破常识、解释 | 发展：换和弦，节奏型开始走 |
| 悬念、破折号 | 挂留或属和弦，**不解决** |
| 概念名、真相 | 解决到主和弦，动机升高八度 |
| 翻转 | 换调式，或全休止后重新进入 |
| 留下的问题 | 抽走乐器，结束在不稳定的音上 |

## 从谱子到画面

| 听到的 | 看到的 | 代码 |
|---|---|---|
| 和弦换 | 世界的状态换：光、场景、镜头方向 | `m.chord`、`m.cue('段落')` |
| 张力升高 | 亮度、饱和度、元素数量一起上升 | `m.tension` |
| 配器变厚 | 画面元素变多 | 段落的 `tension` |
| 音量 | 光和细小的呼吸感 | `m.energy` |
| 动机响起 | 贯穿物亮一下 | `m.motifPulse()` |
| 强拍 | 落点：字、物、镜头到位 | `m.after('提示点', 拍数)` |
| 全休止 | 黑场或静止 | 段落 `rest: true` |
| 音区高低 | 画面上下 | 设计时决定 |

## 节拍和字幕

- **动作按拍算**，不按秒算。`m.after('title', 0.5)` 是半拍，改速度时跟着变。
- **字幕按阅读算**。字幕起点放在拍上，长度按阅读时间，不硬卡每个字。
- **短片硬卡，长片软跟。** 45 秒以内，切点走拍格；90 秒以上，只把几个大转折放到段落线上。
- **速度决定语气。** 选速度时可以念一遍字幕：一屏字的长度最好接近两小节。

## 音效也是音乐

- 带音高的音效传调内的音。重击传主音，它就是和声的根，不是盖在音乐上的噪声。
- 上升类音效的峰值落在拍上，其他音效从拍上开始。引擎已经按这个规则处理。
- 一个动作一个声音，不要全片都用同一个。没有动作，就不要音效。
- 音乐稀疏的地方，音效才听得清。别用音效填空。

## 响度

引擎默认把全片归一到 -14 LUFS，只改电平，不压动态。有配音时，说话段的音乐要比人声低约 10 dB。

## 用引擎写谱

`score.mjs` 只描述结构，张力决定谁来演奏：

```js
{ id: 'because', bars: 1, tension: 0.64, harmony: ['Vsus4'] }
```

| 张力 | 进入的声部 |
|---|---|
| 0.05 | 和弦 |
| 0.28 | 铺底 |
| 0.42 | 低音 |
| 0.62 | 鼓点 |
| 0.78 | 细碎节奏 |
| 0.85 | 高音点缀 |

需要手写旋律时，用段落的 `notes`。段落可以单独换 `mode`、`key`、`palette`：朝堂、玩笑和战场不该是同一个声音。完整例子见 `films/sunk-cost/score.mjs`。

调式除了大小调，还有多利亚、弗里吉亚、利底亚、混合利底亚，以及五声的 `gong`、`yu`。和弦支持 `i`、`VI`、`bII`、`V7`、`Vsus4`、`Imaj7`、`isus2`、`VIIadd9` 这类写法。

## 用户指定现成音乐和配音

在总谱设置 `recording` 后，`npm run music -- <film>` 走现成音轨混音分支，不运行乐器合成器。文件放在已忽略的 `public/films/<film>/`，文件名相对该目录。

```js
recording: {
  file: 'bgm.mp3', offset: 0, lufs: -30,
  fadeIn: 0.35, fadeOut: 1.25, outputLufs: -14,
  voice: {file: 'narration.mp3', offset: 0, end: 19.866, lufs: -18},
  tempoMethod: '记录实际使用的节拍分析方法'
}
```

`end` 是从配音offset起使用的时长。配音按真实同步字幕定时，不能为了拍格改字或移动语音。总谱仍负责片长、段落和cue；引擎从原音乐PCM生成能量时间轴，混音后做两遍响度归一化。`mix-report.json` 留首次测量，最终编码视频仍须复测。命令通过 `FFMPEG_PATH` 或系统PATH查找FFmpeg。

未人工确认的音乐段落，不标为已识别主歌／副歌；未测调性在时间轴记录为unmeasured。含配音成片的自动BPM可能被人声瞬态干扰，不可反过来替代原音乐的分析结果。
