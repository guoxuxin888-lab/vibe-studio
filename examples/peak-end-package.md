# 峰终定律·示例内容包

示例内容包：README 里那条 20 秒的“峰终定律”，就是 Agent 装好两个 Skill 后，从这份内容包做出来的。拿它试一试你的 Agent。

## 选题卡

- 目标：起量
- 片型：概念海报
- 时长：约 20 秒
- 声音形式：纯字幕
- 贯穿物：一条起伏的心情曲线
- 概念名（大字）：峰终定律
- 最像的样本类型：30 秒内讲一个概念的概念海报，避开：黑底金字

## 字幕稿

- 0s 一趟旅行，你记住的不是每一天。
- 3s 是最开心的那一刻，
- 5s 和最后那一天。
- 8s 〔峰终定律〕
- 11s 中间的排队、堵车、下雨，
- 14s 大多会被忘掉。
- 17s 所以，结尾比过程更重要。

## 事实表

| 说法 | 来源 | 状态 |
|---|---|---|
| 人回忆一段经历时，主要依据最强烈的时刻和结束时的感受，经历长短影响很小 | Kahneman, Fredrickson, Schreiber, Redelmeier (1993). When More Pain Is Preferred to Less: Adding a Better End. Psychological Science, 4(6) | 已核 |
| “峰终定律”是这一现象的通行中文名 | 卡尼曼《思考，快与慢》中文版相关章节 | 已核 |
| 旅行里的排队、堵车、下雨会被忘掉 | 解释用的例子 | 示意 |

## 给制作的提示

- 第 8 秒“峰终定律”四个字要当大字出现，心情曲线的最高点和最后一点在这时亮起来。
- 画面要让人看出：曲线中间的低谷变淡，只剩一个高点和结尾。
