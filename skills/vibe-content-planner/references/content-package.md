# 内容包

内容包是策划和制作之间唯一的交接文件。制作只认它：字幕、事实和时长都以它为准。

## 位置和文件名

`profile.local.md` 里写了位置就放那里；没写就放工程根目录的 `content/YYYY-MM/<片名>·内容包.md`。开始制作时，制作会把它复制一份到 `films/<slug>/content-package.md`。

## 模板

```markdown
---
title: "<片名>·内容包"
status: 策划中
账号: <你的账号>
---

# <片名>·内容包

## 选题卡

- 目标：收藏 / 转发 / 评论 / 起量
- 片型：
- 时长：约 __ 秒
- 声音形式：纯字幕 / 配音
- 贯穿物：
- 概念名（大字）：
- 最像的样本类型：，避开：

## 字幕稿

- 0s 第一句
- 3s 第二句

## 事实表

| 说法 | 来源 | 状态 |
|---|---|---|
| 1985 年某实验 | 作者、年份、论文或书名 | 已核 |

## 给制作的提示

只写内容上必须成立的东西，比如“第 30 秒要让人看出两组人差一倍”。画风、配色、镜头不写。

## 制作记录

（制作填写：工程目录、成片路径、最终时长）
```

## 规则

- 状态只按真实进度改：`策划中` → `待制作`（用户确认稿子）→ `制作中` → `待发布` → `已发布`。
- `待制作` 时，事实表每条都要有来源，状态不能是 `待查`。说法没有依据就从稿子里删掉。纯情绪片没有可查的事实时，写一行“无需核查的事实”和原因。
- 声音形式为纯字幕时，字幕稿每行一屏，行首是大约第几秒。`〔 〕` 里是必须出现的画面文字，比如大字和图内标签。声音形式为配音时，“字幕稿”这一节保存完整口播自然段，不为分屏切碎口语；录音后再依实际人声导出 SRT。
- 故事类在“选题卡”中说明主事件、对外话题、观众疑问及正文怎样回答，避免把内部事件名直接当发布标题。
- 稿子定了以后，制作想改字要提回策划。策划改完在内容包里改，工程重新同步。
- 工程里的 `node tools/check-package.mjs <内容包.md>` 会检查格式和状态。
