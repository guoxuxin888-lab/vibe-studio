# Vibe 故事类视频：用话题引入，用事件回答

适用：历史故事、小说讲解、人物故事，以及用故事说明书中观点的 Vibe 知识分享视频。

这套方法把短视频创作者薛辉总结的“八大元素”定制为故事的取材和开头工具，是作者在 2026-11 整理的创作方案，尚无传播效果验证。八项原名保留：**成本、人群、猎奇、反差、最差、荷尔蒙、头牌、怀旧**。案例与确认状态见 `references/story-examples.md`。

## 1. 分清主事件、对外话题与开头入口

| 层次 | 要解决什么 | 作用 |
|---|---|---|
| 主事件 | 本篇讲哪件有起因、行动与结果的事 | 限定正文的因果主线，避免散讲 |
| 对外话题 | 普通观众为什么愿意听，想弄明白什么 | 表达观看理由，可以来自认知冲突、具体处境或值得追问的事实 |
| 开头入口 | 用哪句话或哪段现场引入 | 按材料选问题、判断、动作、画面或对白 |

**事件优先是创作依据，话题先行可以是观看顺序。** 先掌握有出处的事件，从中提炼观众在意的问题，再组织情绪与文案；成片可按“话题 → 事件 → 转折与结果 → 回答话题”展开。已有用户认可的话题时，先检验事件能否回答，不因事件排期而擅自换成事件名。

“蔡邕上书被逐”可作内部事件名；“汉朝还没亡，天下为什么先乱了？”表达对外话题。陌生人名和事件名本身未必提供观看理由，可以先给观众能理解的处境或矛盾，再介绍人物。人物知名度高，或具体场面本身足够吸引人时，也可直接从名字、动作或对白进入，不要求先念一个问题。

认知冲突要落实到能解释的事情，例如“朝廷本该解决问题，提出问题的人为什么先被处理”。这是本篇打算引起的疑问，不预设所有观众都持有同一种看法，也不凭空编造大众共识。普通观众的入口不等于每篇都要落到当代痛点、职场比喻或人生道理。

开头可以先让观众关心人物遇到了什么，再逐步带出知识疑问，也可以先提出话题再让人物登场。名字可后揭，问题可隐含；没有固定句数、字数、问句或反差模板。

### 让事件足以回答话题

- 遇到“每集一个事件”的连载要求时，保持一条集中的因果主线；同一次事件的准备、实施、转折与结果可以连贯展开，不把主事件机械压成某个人的单个动作。
- 话题问“怎样形成起兵力量”，正文只讲“告密使计划败露”就答不全。应调整话题范围，或将主事件扩到同一次起事的组织与发动；不靠拼入无关故事凑证明。示例见 `references/story-examples.md`。
- 分清“用事件说明一个机制”与“证明整个历史结果的全部原因”。标题的解释范围应有对应材料，不能从一个案例推出唯一原因。
- 开头引出的疑问，后文用情节、原文或证据回答；吸引人的标题和正文要讲同一件事，不能只借名人或猎奇把人引进来。
- 有合适物件时，可用它承接讲述，如奏疏、告示或一封信；没有时由选择或冲突贯穿，不强行发明道具。
- “别人不知道”来自真实的信息差，不宣称所有人都不知，不为陌生感编奇闻。

## 2. 八种元素，八种故事入口

下表是面向 Vibe 知识分享的应用设计，不冒充薛辉原话，也不是八套固定标题。

| 原元素 | Vibe 故事入口 | 开头从哪里取材 | 后文用什么回答 |
|---|---|---|---|
| 成本 | **选择的代价** | 为得到某样东西，人物已经付出或将承担什么；本方案把钱、时间扩展到名声、感情、权力、生命等代价 | 为什么愿意付出，受什么条件限制，最后换来什么；不擅换算现代金额 |
| 人群 | **身份里的处境** | 让某类观众认识自己的难题：想做事却没资源、有本事不受重用、夹在亲人之间；先落到具体人物和事件 | 这种处境怎样影响选择；不把所有古人硬写成现代打工人 |
| 猎奇 | **陌生细节背后的规则** | 有出处的少见物件、生活细节、制度操作或经历，引出“这是什么、为什么会这样” | 补足当时规则与背景，让细节服务理解，不停在奇闻 |
| 反差 | **熟悉形象里的意外行为** | 观众熟悉的身份、形象，与一个有依据的行为或处境形成落差 | 交代前因、限制和后果；不篡改事实，也不预设所有观众都有同一种印象 |
| 最差 | **坏结果是怎样形成的** | 严重失败、困境或错误决定，从可证的坏结果或出问题的一刻进入 | 还原哪一步出了问题、有哪些因素；无比较依据不封“史上最差” |
| 荷尔蒙 | **吸引与亲密关系中的选择** | 爱情、吸引、婚姻选择，或亲密关系里的嫉妒与争夺，具体到一次行动 | 这段关系怎样改变决定与命运；不把所有人际关系、权力欲都归入荷尔蒙 |
| 头牌 | **熟悉名字的陌生一刻** | 名人、名著、著名事件中的一个具体行为、难题或未被讲透的片段 | 讲明这件事及其背景；不能只报大名，也不靠作者轶事替代书中内容 |
| 怀旧 | **熟悉记忆留下的疑问** | 观众真实的读书、看剧记忆：一句台词、一个场景、一段当年熟悉的情节 | 回到原书或注明的改编版本解释；不把电视剧细节当史实，不以“你小时候根本没看懂”代替内容 |

通常找一个主入口，必要时加一个辅助元素；材料只适合直接提问、判断或场景，也可以不硬贴八项标签。不要每篇叠满，不以标签数量衡量质量。

## 3. 元素怎样变成第一句

**元素决定挑哪段材料，表达方式决定怎样让人听懂或看见。** 同一种元素可用不同说法：

- **问题**：材料中确有一个值得解释的矛盾，直接问。
- **动作或画面**：现场本身够抓人，先说谁正在做什么，再补身份或背景。
- **对白**：原文中一句话已经把冲突带出来，用原话或明确的口语转述进入。
- **直接判断或结果**：有充分依据的结论可以先讲，随后给事件与理由，不一律改成问句。
- **具体处境**：先把人放进难题，让观众知道他想做什么、眼前被什么阻住。

这些方式可以组合，不要求固定顺序、字数或每条反问。比较备选开头时，判断哪一个更贴合当前材料、信息更具体、后文更能回答；不为了区别上一集而硬换入口。

### 写之前留一张简短分析卡

可作为工作记录或交稿说明，按现有内容包结构写，不增加制作端必填字段：

- 主事件与来源版本是什么，起因、行动和结果是否形成一条主线？
- 对外话题是什么，普通观众为何在意，会追问什么？
- 主事件中的哪段情节或证据能回答话题，解释范围是否匹配？
- 主入口是什么，拟从问题、动作、对白、结果还是处境引入，是否确需辅助元素？
- 从哪里转入事件和背景，转折与结尾怎样回答话题或留下有意义的变化？

已有明确选题、连载排期或用户确认句时，直接在其范围内选入口，不重新要求用户选题，不擅改已确认正文。备选开头按任务需要给，不固定数量。

## 4. 三类题材的知识主线

| 题材 | 主线 | 开头与正文怎样配合 |
|---|---|---|
| 历史故事 | 当时的选择、条件与实际后果 | 从关键事件进入，再讲人物知道什么、能做什么、为什么这样选；区分史料、小说与解释 |
| 讲书 | 一段情节或一个问题怎样被书解释 | 小说从有张力的情节进入；知识类书从具体问题进入，接作者的解释、论据、反例和适用范围 |
| 人物故事 | 一次选择怎样显出性格并改变处境 | 从一场有依据的经历进入，讲想要什么、遇到什么、怎么做、付出什么、后来怎样；整个人生按本篇问题取舍 |

三类可以重叠。讲《三国演义》首先按小说版本讲；引用史料比较时明确切换来源，不把小说情节直接算作史实。

连载优先保持当前情节与前后集关系，在当前材料里挑入口。单篇可从后来的一刻回溯，但必须说明时间变化；不能为开头刺激把后期事件挪成当前已发生。

## 5. 正文怎样兑现开头

正文落实到具体事件，按话题需要交代背景与解释，保持人物在场。开头可先抛话题，再让人物登场；以下检查正文是否真正回答了它：

1. 谁在哪里，眼前有什么。
2. 他做了什么，或怎样说。
3. 对方怎样回应，事情因此发生什么变化。
4. 回到开头的疑问，用情节、原文或证据讲清原因与后果。

这四项是检查场面是否清楚，不是每段必须填满的模板。重要场面适当展开，过渡部分可以简洁交代。

- **白话说书**：外貌、动作、神态和对白都用今天能理解的话。原文“丹凤眼”可按语境解释为眼角上挑；这只是风格例子，不要求每个人都写眼睛。没有依据的五官、身高厘米数、动作与心理不补。
- **情绪来自可证的行为**：写叹气、拒绝、离开或有出处的说话方式，让听众理解情绪。不是只给停顿、重音、喊叫提示，也不擅加“被问住了”等反应。
- **现代类比**：用在难理解的制度、资源或利益关系处，明确是解释用的比方；用完回到人物。不要按古代身价换算精确现代金额，也不把不同制度直接等同。
- **自然口语**：保留完整意思、因果和并行关系，不为节奏切碎句子。口头禅和用词习惯写在 `profile.local.md` 里。
- **结尾**：回答本篇的问题或停在有意义的结果、行动、变化上。连载可引出下一集，不强制升华道理或每集都留反问。

## 6. 来源与交稿自查

- 每项事实定位到文献、书名及章回/章节；年代、数字、引言、动作、五官与先后顺序都能回查。
- 原文引用、口语转述、现代类比、解释推测分别标清。推测人物动机时给依据，不能由一句台词直接断言真实用意。
- 标明“用户确认句 / 试写待确认 / 创意待核 / 原文已核但解读待论证”等状态；表达偏好获认可不等于传播效果已验证。
- 检查开头是否被正文回答，是否混用了史料、小说与影视改编，是否无依据增加“唯一、最后、提前”等限定词。
- 检查用户已确认的措辞是否原样保留。示例见 `references/story-examples.md`；`profile.local.md` 里有写作卡或口语风格要求时同时核对。
